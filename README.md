# Jumoke's 35th Floor

Build a mobile-first, chic, and playful 35th birthday web app for Jumoke with the theme "Welcome to the 35th Floor".

Aesthetic & Theme:
- Very girly, elegant, pink, blush, rose gold, and cream aesthetic with subtle sparkles and micro-animations.
- Fully responsive and optimized for mobile devices as well as laptops.

Features & Flow:
1. Homepage ("The Lobby / 35th Floor Entrance"):
   - Headline: "Happy Birthday Jumoke! Welcome to the 35th Floor"
   - Interactive stylish wrapped gift box with a ribbon and an "Open Me" button.
   - Tapping it triggers a burst of celebration confetti and smoothly opens Card #1.

2. 35 Interactive Cards ("Floor 1" to "Floor 35"):
   - Uses Jumoke's uploaded portrait (attached) as the centerpiece.
   - For each card, render playful, stylish SVG / CSS overlays and doodles on her photo matching birthday and mood themes (e.g., party cone hats, chic heart sunglasses, cat-eye glasses, princess tiara, floral crowns, star doodles, cheek glitter, champagne glass toast, party horns, floating hearts).
   - Display the floor number (1 to 35), the punchy word, and its warm, funny, personal definition.
   - No em dashes anywhere in the text (use hyphens, commas, or parentheses).
   - Smooth navigation: easy "Next" and "Back" buttons, touch swipe gestures on mobile, keyboard arrows on desktop, and a sleek progress counter ("Floor X of 35").
